Help & Documentation

1. Getting Started

Tap API key… in the menu (or open Settings), paste your XPIKI API key, and tap Save & test connection. The app fetches the live `/models` list from your endpoint and selects the first available model automatically.

2. Arabic & Bilingual Rendering

Arabic and mixed Arabic/English paragraphs use native Unicode bidirectional shaping (`dir="auto"` per block) with zero character reversal. Code blocks always stay left-to-right.

3. Attachments & Quick / Full Coverage

Attach up to 3 images (JPG, PNG, WebP) and 20 text/code documents per chat. When attached documents exceed 12,000 characters, you will be prompted to choose Quick Analysis (1 request, lexical excerpt retrieval, max 300 tokens), Full Analysis (processes every 24,000-char section then consolidates), or Cancel.

4. Error Handling

HTTP 401/403 prompts to replace your key without deleting chat history. HTTP 402 reports quota/balance limits. HTTP 429/5xx reports temporary rate or capacity limits and restores your unsent question so retrying never duplicates your user turn.
